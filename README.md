# 🌟 Sahayak AI Platform

Sahayak AI is a next-generation, AI-powered smart resource allocation platform built to revolutionize how NGOs, volunteers, and donors respond to community needs and crisis situations. Designed with a sleek **dark-themed glassmorphic UI**, the platform ensures that help reaches exactly where it is needed—quickly, efficiently, and intelligently.

## ✨ Key Features

### 🤖 AI Priority Scoring

* Automatically evaluates and prioritizes crisis situations.
* Uses intelligent ranking to allocate resources where urgency is highest.

### 🗺️ Interactive Live Mapping

* Real-time tracking of:

  * Volunteers
  * Crisis locations
* Powered by **Leaflet** for dynamic and responsive mapping.

### 📊 Role-Based Dashboards

Tailored dashboards for different users:

* **🏢 NGOs**

  * Monitor requests
  * Dispatch resources
* **🙋 Volunteers**

  * View assigned tasks
  * Track routes in real-time
* **💰 Owners/Donors**

  * Track donations
  * Monitor inventory & usage
* **🌍 General Users**

  * Report crises
  * Request emergency help

### 📦 Smart Inventory Management

* Real-time tracking of essential supplies:

  * Food 🍱
  * Water 💧
  * Clothing 👕

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Sandilyamishraabhishek/Sahayak-AI-Platform.git
cd Sahayak-AI-Platform
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Run the Development Server

```bash
npm run dev
```

### 4️⃣ Build for Production

```bash
npm run build
```

---

## 🌐 Deployment

This project is deployed using **Firebase Hosting**.

To deploy your own version:

```bash
npm run build
firebase deploy
```
